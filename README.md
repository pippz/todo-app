# To-Do List Web App

A full stack productivity app built with Python and Flask, featuring task management, notes, and a calendar view.

## Live Demo
[Watch the demo](#) ← replace this with your video link once you upload it

## Features
- Add, edit, delete and complete tasks
- Priority levels (low, medium, high)
- Due dates with calendar view
- Sort tasks by priority, due date or status
- Notes section with a full editor
- Data persistence with JSON
- Clean dark theme with purple accent

## Built With
- Python
- Flask
- HTML / CSS / JavaScript
- FullCalendar.js
